# Marchés Publics — Public Probe Lab

Isolated read-only diagnostics for the official Moroccan public tender portal. No credentials, database connections, personal data, DCE submissions, or automated protected downloads. No production use. This repository is public, so artifacts must exclude sensitive data.

Gate 1: connectivity, public Fournitures results, stable pagination. Gate 4: read-only document access inspection, not a verified DCE download.
